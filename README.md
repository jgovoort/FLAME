# FLAME

**F**ibre-optic monitoring of icelandic vo**L**canic hydrothermal **A**ctivity using strain and temperature **ME**asurements.

[![DOI](https://zenodo.org/badge/1355753486.svg)](https://doi.org/10.5281/zenodo.23887221)

FLAME is a research repository for processing and analysing fibre-optic and
geophysical observations from Icelandic volcanic and hydrothermal environments.
The project combines Fiber Bragg Grating (FBG), Distributed Acoustic Sensing
(DAS), GNSS, InSAR, weather, and earthquake data to investigate strain,
temperature, deformation, and recurrent signals.

## Repository contents

| Directory | Description |
| --- | --- |
| [`PyBSI/`](PyBSI/) | Python readers and conversion utilities for BSI FBG files. See the [PyBSI README](PyBSI/README.md). |
| [`Notebooks/`](Notebooks/) | Jupyter notebooks for preprocessing, comparisons, signal analysis, clustering, and localisation. |
| [`data/`](data/) | Small example and analysis data files used by the project. Large or restricted datasets are not necessarily included. |
| [`plots/`](plots/) | Figures generated by selected analyses. |

## Getting started

Clone the repository and create an isolated Python environment:

```bash
git clone https://github.com/jgovoort/FLAME.git
cd FLAME
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

The repository does not currently provide a lockfile or dependency manifest.
The notebooks use common scientific Python packages, including NumPy, pandas,
SciPy, Matplotlib, xarray, tqdm, and scikit-learn. Some notebooks additionally
use ObsPy, rasterio/rioxarray, tifffile, utm, openpyxl, or netCDF support.
Install the packages needed by the notebook or analysis you intend to run.
For example:

```bash
python -m pip install numpy pandas scipy matplotlib xarray tqdm scikit-learn \
  netcdf4 jupyter
```

`PyBSI` has additional requirements:

```bash
python -m pip install numpy pandas xarray
```

From the repository root, the package can be imported directly:

```python
from PyBSI.low_sampling import read

absolute_time, reference_time, wavelengths, reference_wavelength = read(
    "path/to/BSI_file.txt",
    nChannel=8,
    maxFBGs=12,
)
```

See [`PyBSI/README.md`](PyBSI/README.md) for input expectations, conversion
examples, and the available reader functions.

## Typical workflow

1. Acquire or prepare BSI, DAS, GNSS, InSAR, weather, or earthquake data.
2. Use `PyBSI` to read BSI FBG text files and export time-indexed NetCDF files.
3. Open the resulting data with xarray or pandas for quality control and
   preprocessing.
4. Run the relevant notebook in [`Notebooks/`](Notebooks/) to reproduce an
   analysis or generate a figure.
5. Store generated figures in the appropriate subdirectory of [`plots/`](plots/).

Notebook paths are organised by data type, for example:

- `Notebooks/FBG/` for FBG strain, temperature, preprocessing, comparisons,
  and signal analysis.
- `Notebooks/DAS/` for DAS clustering and conversion from strain rate to strain.
- `Notebooks/InSAR/` for InSAR-to-strain processing.

## Data and reproducibility

Paths in notebooks may refer to local acquisition systems or datasets that are
not part of this repository. Before running a notebook, update its input paths
and confirm that the expected files are available. Generated NetCDF files and
figures can be large; avoid committing intermediate outputs unless they are
needed to document or reproduce an analysis.
